# Playground

Play Doge Miner 2 in an iframe from the official browser game at <https://dogeminer2.com/play/>. Use **Open directly** if the external site blocks embedding.

## Deploy

The GitHub Pages workflow deploys only `index.html` and `styles.css` to <https://vinsanity121.github.io/playground-game-hub/>. Cloudflare deployment also runs on pushes to `main` and requires the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` repository secrets.
